# Just A Player 0.1.4

让原生轻量模式真正轻下来，补齐桌面后台播放与托盘。

- **降低内存**：桌面原生界面改用 CPU 缓存光栅化，不再创建设备级 GPU 渲染上下文。Windows x64 本机 Release 测量：空闲约 52 MiB 工作集，48 kHz PCM 播放并开启 VU 约 66 MiB，收起到托盘约 36 MiB。实际占用随音色库、解码器、封面及缓冲配置变化。
- **后台与托盘**：默认允许后台播放，关闭窗口收起到托盘；右键原生面板提供封面、上一首 / 播放暂停 / 下一首、缓冲重置、恢复和退出。主窗口与托盘面板共用一个音频引擎和一个窗口，隐藏或最小化释放绘制资源、停止 FFT，后台自动切歌和系统媒体控制继续工作。相关设置可单独调整。
- **降低后台 CPU**：修复音频生产线程在包数据尚未写完、环形缓冲已满时持续忙等的问题；等待期间仍可及时处理播放控制、切歌和退出。
- **统一图标**：轻量界面中的 J 占位改为应用图标，无封面占位与托盘同步统一；Windows 标题栏和可执行文件嵌入应用图标与正式名称，托盘图标保留透明圆角。
- **列表与验证**：列表只布局当前可见行；新增实际窗口图标、后台播放、托盘按钮、最小化、恢复、反复收起和进程内存回归检查。

Windows / macOS / Linux 提供 x64 与 ARM64 安装包；Android 提供四 ABI universal、固定密钥签名的 Release APK。每种安装格式均分为 `with-midi` 与 `without-midi`：后者仅不附带大型 SF2，仍保留 MIDI 播放和自定义音色导入。

Linux 原生托盘需要桌面提供 StatusNotifierItem 宿主；没有托盘宿主时关闭窗口会正常退出，不会隐藏到无法恢复的位置。鸿蒙仍为预览适配，不包含在本次正式安装包中。

附带 FFmpeg / ffprobe、对应源码、第三方许可证和 SHA-256 校验。GPL-3.0-or-later，作者 B5-Software。
