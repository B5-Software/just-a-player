# Just A Player 0.1.9

- 恢复首版的声波星球、星云漩涡、时空隧道、光之都市、相位丝带和熔岩极光，也接入首版代码中的频谱山脉。可在设置中分别开启。
- 桌面端和 Android SDR 使用恢复后的场景。Android 原生 HDR 使用对应的便携着色器，后台导出沿用入队时的场景版本。

Windows、macOS 和 Linux 提供 x64 与 ARM64 安装包。Android 提供签名 Universal Release APK。各安装格式均提供 with-midi 和 without-midi 两种版本，均支持导入 SF2。

## English

- Restore the original scenes for Orb, Galaxy, Tunnel, City, Ribbon and Plasma, and make the original Spectrum Terrain scene available. Enable each scene separately in Settings.
- Desktop and Android SDR use the restored scenes. Android native HDR uses the corresponding portable shaders. Background exports use the scene variant captured when the job was queued.

Windows, macOS and Linux installers are available for x64 and ARM64. Android downloads are signed Universal Release APKs. Both with-midi and without-midi editions support imported SF2 banks.
