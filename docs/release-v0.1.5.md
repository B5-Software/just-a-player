# Just A Player 0.1.5

本次补齐外部播放器接管，并修复在线封面与 DSP 预置。

- **连接网易云**：Windows 完整版和 Rust 原生 GUI 均可连接本机 64 位客户端，支持播放暂停、切歌、跳转、歌词、封面和元数据同步。客户端专用黑洞设备不打开物理 DAC；FLAC 优先转交原始压缩包，其他支持的格式可转交音效处理前的原生 PCM，由本播放器的 Rust 内核输出。
- **强制接管**：可跳过版本白名单，尝试模块编号变化和更多 PCM 格式；保留数据边界、时间戳及内存上限检查。已验证网易云 3.1.41 x64，其他版本属于尝试适配。
- **在线封面修复**：按实际图片头识别 JPEG / PNG / WebP，兼容网易云 CDN 的 `image/jpg` 返回值；下载失败自动重试，切歌取消旧请求，避免空封面或旧结果覆盖当前歌曲。
- **DSP 预置修复**：修复自绘下拉框缺省选项值为空的问题。选预置后自动启用 DSP，保留所选名称、更新曲线并保存参数；原生 GUI 统一提供平直、温暖、人声、摇滚、爵士、清亮、耳机串音七种预置。DSD 直通仍绕过 DSP，需切为 PCM 后使用音效。
- **原生模式接管**：原生窗口、仪表、解码、DSP 与硬件输出继续由 Rust 执行；仅连接时启动无界面的客户端适配进程，通过有界二进制管道传递音频。断开后退出适配进程，释放连接资源。后台、托盘及系统媒体控制共用同一 Rust 引擎。
- **路由连续性**：暂停时停止收取客户端预解码数据；恢复、跳转和重置时重新同步，丢弃旧代数据，避免旧缓冲覆盖新时间轴。退出先释放 Rust 输出，再恢复客户端原来的设备。

无损 FLAC 已做软件样本一致性验证。实际 DAC 的 bit-perfect 取决于独占输出、原生格式、关闭 DSP 和应用音量 100%；AAC / MP3 转发不会还原有损信息。未连接时不加载进程接管组件。

Windows / macOS / Linux 提供 x64 与 ARM64，Android 提供四 ABI universal、固定密钥签名的 Release APK。各安装格式均提供 `with-midi` / `without-midi`；后者保留 MIDI 合成与 SF2 导入，只省去内置大型音色库。鸿蒙仍为预览适配。

附带 FFmpeg / ffprobe、对应源码、第三方许可和 SHA-256 校验。GPL-3.0-or-later，作者 B5-Software。
