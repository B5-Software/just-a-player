# Just A Player 0.1.2

HiFi 与可视化，现在也来到 Android。界面沿用桌面设计，强制横屏，支持原生音频、后台播放、系统媒体控制、画中画与 USB Host 独占输出。

- **两种安装包**：每个平台、每个架构和格式均提供 `without-midi` 与 `with-midi`。轻量版省去约 467 MiB 的内置音色资源，可自行导入 SF2；完整版内置 MuseScore General HQ。桌面覆盖 Windows / macOS / Linux x64 与 ARM64，Android 为包含四种 ABI 的 universal APK。
- **MIDI**：全平台共用 Rust 合成器，96 kHz Float32、512 复音、7 阶插值，支持多轨、速度、踏板、弯音和鼓组；可导出为 FLAC / PCM 视频音轨。
- **系统打开方式**：直接打开音频并追加到“外部打开”列表，保留原歌单；Android 处理文件管理器授予的 content URI。
- **触屏**：修复舞台与歌词拖动中断、轻点无法唤醒控件；所有滑动条需明确拖动，竖向 EQ 先短按再拖动，列表提供排序把手。
- **Android 布局**：按实际像素尺寸计算独立的横屏界面比例，调整系统 DPI 不会挤压布局；设置中可单独调节界面大小，绘制分辨率继续匹配屏幕。
- **光盘与高采样率**：SACD ISO 与 CD/CUE 按曲目导入，保留专辑、曲名与每首边界，支持独立跳转和导出；修复 24-bit / 768 kHz FLAC 的采样率限制与短 FLAC 精确跳转。
- **流式与设备适配**：原生读取 float64 RF64 / BW64 WAV，按块解码而不载入整首；输出能力表展示设备报告的格式，不支持时自动抗混叠降采样和位深适配，标明非 bit-perfect。
- **逐字歌词与 VU**：读取音频内嵌 LYRICS，支持 LDDC 方括号与增强 LRC 时间戳；2D、3D 和视频按同一时钟逐字高亮。新增独立 VU 表开关，默认关闭。
- **小窗导入**：小窗的打开音频操作使用系统文件选择器；后台扫描跳过无法解析的普通数据 ISO，不再反复弹出缺少 CUE 的错误。
- **小窗与常亮**：Android 小窗按实际画中画高度适配，提供系统上一首 / 播放暂停 / 下一首；增加播放时保持屏幕常亮设置。
- **新的可视化**：丝境、潮汐、风痕、折光成为默认效果，每个可独立开关；可导入 JSON / GLSL 插件。附加场景与仪表默认隐藏，各自有独立开关；移植为共享 GPU 着色器，统一实时、HDR 和导出，加入边缘抗锯齿。
- **Android HDR**：全部内置效果直接由原生 GPU 绘制，共用 GLSL、无逐帧像素回读；分辨率和帧率跟随画质设置，取消 720p / 30 FPS 限制。默认关闭。具体手机的驱动、HDR 亮度和 USB / DSD 档位仍需对应硬件验证。
- **后台视频**：按音频时间离线生成，共用实时效果与歌词定义；优先系统 GPU 视频编码，FFmpeg 回退。Android 改为独立进程，通过管道传输帧；默认给前台留出计算资源，取消任务直接释放后台实例。
- **安装即可使用**：随包提供各架构 FFmpeg / ffprobe，支持扩展音频格式与独立后台视频导出。

Android 下载附件为固定密钥签名的 **Release** 构建，关闭调试。两种音色版本可相互覆盖升级；旧 `.debug` 测试包是独立应用。推荐不播放 MIDI 的用户选择 `without-midi`。
